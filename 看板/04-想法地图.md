# 想法地图

[[README|演示导航]]

Map View 读取每条记录中的 `geo:` 链接并聚合成地图标记。点击标记可回到对应笔记；放大可展开聚合点。

```mapview
{"name": "Sparkle 演示", "mapZoom": 7, "centerLat": 31.0, "centerLng": 120.6, "query": "(path:\"日记/\" OR path:\"主题/\")", "chosenMapSource": 1, "autoFit": true, "lock": false, "showLinks": false, "embeddedHeight": 470, "customViewSettings": {"showFilters": true, "showView": true, "showSearch": false, "showRouting": false, "showRealTimeButton": false}}
```

底图：© [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)，需联网，无需 API Key。

预设示例：[[看板/04b-杭州位置|只看杭州的想法]]。

Map View 过滤框可用 `(path:"日记/" OR path:"主题/") AND name:"杭州"`。笔记已添加 Map View 要求的 `locations:` 属性；新日记模板也会自动带上。
