## 试写一条

打开 [[主题/产品-Sparkle|产品-Sparkle]]，运行 Sparkle 快速记录或连续记录命令，切换“当前笔记 / 今日日记”，试试 `#`、图片和位置。保存后可在汇总页看到新记录。

日记目录为 `日记`。DataviewJS 按条汇总、Charts 绘图、Map View 显示位置，Bases 按笔记展示；地图使用 OpenStreetMap，无需 API Key，需联网。插件已配置，必要时重载 Obsidian，用阅读视图打开看板。
